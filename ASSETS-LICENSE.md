## What is not here, on purpose

- No textures, sounds, music, models, fonts or code from Minecraft (Mojang Studios / Microsoft)
  or Terraria (Re-Logic). Names of game mechanics are used only to describe what our own
  implementation does.
- No third-party resource packs. The game can load a Minecraft resource pack that the player
  owns from their own `resourcepacks/` folder, but such packs are never committed or shipped.
- No leaked or decompiled source code of any game. The design comes from public descriptions
  (wikis, changelogs) and from open-source projects with compatible licences.

If you think a file in this repository should not be here, please open an issue and it will be
removed.
